# Expo v54.0.0 Guidelines

## Context
Expo has updated to SDK 54, and it is critical to follow the v54.0.0 documentation.

## Requirements
1. **Versioned Docs**: Always consult the exact versioned documentation at https://docs.expo.dev/versions/v54.0.0/ before writing or modifying any Expo/React Native code.
2. **Tech Stack**:
   - Expo SDK 54 (`~54.0.33`)
   - React Native (`0.81.5`)
   - `expo-router` (`~6.0.23`) for file-based routing.
   - `expo-sqlite` (`^55.0.16`) for relational SQLite storage.
   - Zustand (`^5.0.13`) for state management.
